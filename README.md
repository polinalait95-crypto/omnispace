# OmniSpace

Личный AI-ассистент для задач, знаний и финансов. Local-first, ставится на
свой компьютер (Windows и macOS Intel), данные не покидают устройство.

## Что готово

**Ход 2 — фундамент.** Каркас Tauri + слой данных на общем «хребте»
(12 таблиц: единая `entities` + типизированные расширения + связи + журнал
`events`). SQLite компилируется внутрь (rusqlite `bundled`, FTS5/JSON1),
метки времени в миллисекундах.

**Ход 3 — модуль «Задачи».** Канбан с drag-and-drop, список, поиск, ⌘K.

**Ход 4 — модуль «Финансы».** Транзакции, аналитика, конверты, ⌘K про деньги.

**Ход 5 — модуль «База знаний».** Дерево, редактор, версии, бэклинки.

**Ход 6 — модуль «Подписки» (трекер) + хранение файлов.**
- Rust: подписки со статусами, вычисляемыми из дат продления
  (active / expiring / overdue), ручная пауза/отмена перекрывает авто-статус.
  **Вложения**: файлы пишутся на диск в `files/`, метаданные — в БД; чтение,
  скачивание, удаление. Проверено компиляцией (7/7, включая запись файла).
- Фронтенд: карточки подписок со статусами и фильтрами, добавление, действия
  (пауза/отмена/активация), прикрепление файлов (счетов) с загрузкой и
  скачиванием. Оплаты — на паузе, как договорились.

## Хранение данных

Всё локально на твоём Маке, ничего в облаке, без ключа Claude:
- **БД** — `omnispace.db` в `~/Library/Application Support/app.omnispace.desktop/`.
  Каждое изменение — транзакция SQLite (WAL), сохраняется мгновенно и надёжно.
- **История** — журнал `events` (append-only): все создания, правки, смены
  статуса, удаления пишутся со снимком «до/после». Ничего не теряется.
- **Файлы** — на диске в подпапке `files/`, метаданные в таблице `attachments`.
- **Бэкап** — весь каталог данных можно просто скопировать.

AI-функции (Carmen, обработка документов) будут работать **локально** через
бесплатный Ollama или на правилах — интернет и ключи не нужны.

**Ход 6.1 — редактирование и удаление везде.**
- Rust: `update_task`, `update_transaction`, `update_subscription`; корзина
  (`list_trash`), восстановление, окончательное удаление (`purge`) с
  корректными каскадами (история и связи чистятся, FK не нарушается).
  Проверено компиляцией (6/6).
- Фронтенд: модалки редактирования и кнопки удаления в Задачах и Подписках.
  (Финансы и База знаний + раздел «Корзина» — Ход 6.2.)

**Ход 6.2 — редактирование/удаление везде + Корзина.**
- Финансы: редактирование и удаление операций (модалка).
- База знаний: удаление страниц (в дереве).
- Новый раздел **«Корзина»**: всё мягко удалённое собирается здесь, можно
  восстановить или удалить навсегда (с очисткой файлов и истории).
- Проверено строгим `tsc`. Правило «всё создаётся, редактируется, удаляется»
  теперь выполняется во всех модулях.

**Ход 7 — Календарь + уведомления.**
- Rust: `calendar_items(from,to)` собирает дедлайны задач и даты продления
  подписок в один поток (статус подписок вычисляется), сортирует по дате.
  Проверено компиляцией (4/4).
- Фронтенд: модуль «Календарь» — месячная сетка с событиями по дням, навигация
  по месяцам, «Сегодня», детали выбранного дня, цветовая легенда. Панель
  напоминаний по колокольчику: ближайшие дедлайны и продления + просроченное,
  клик ведёт в нужный раздел.

> OS-уведомления (всплывающие) можно включить позже через плагин Tauri —
> сейчас напоминания в самом приложении, полностью локально.

**Ход 8 — Carmen AI (локально, без облака).**
- Rust: диалоги (`chat_session`) и сообщения (`chat_messages`) — сохранение,
  порядок, meta карточек, авто-заголовок из первого сообщения, всплытие
  активной сессии. Проверено компиляцией (4/4).
- «Мозг» Carmen — детерминированные правила поверх слоя действий: распознаёт
  запрос → выполняет реальное действие через API → отвечает и показывает
  интерактивную карточку. Маршрутизация проверена на 9 запросах.
- Умеет: создать задачу, записать расход/доход, показать финансовую сводку,
  статусы подписок, ближайшие события, поиск по пространству. Карточки ведут
  в нужный раздел.
- Интерфейс: список диалогов с историей, чат, композер. Данные не покидают Мак.

> Опционально позже: локальная модель Ollama как запасной парсер для свободных
> формулировок — тоже без интернета и ключей.

**Ход 9 — Кастомизация.**
- Rust: чтение и сохранение настроек (`preferences`) — upsert одной строки,
  переживает перезапуск. Проверено компиляцией (4/4).
- Фронтенд: раздел «Настройки» — 5 металлических тем (Графит, Лён, Медь,
  Аметист, Оникс), обои (5 пресетов), шрифт и его размер, часовой пояс, формат
  времени (12/24) и даты. Всё применяется вживую и сохраняется в БД; часы и
  календарь учитывают часовой пояс.

**Ход 10 — AI-обработка документов (локально).**
- Rust: дерево правил (`doc_rules`) — папки и правила, CRUD, каскадное
  удаление папки. Проверено компиляцией (4/4).
- Фронтенд: боковое дерево правил с созданием/редактированием/удалением,
  редактор правила (типы файлов, действие, промпт с переменными), приём файла
  с локальным превью текст/CSV и честной пометкой, что разбор PDF/DOCX/XLSX
  идёт локально при запуске (pdf/docx/xlsx + Ollama). Генератор таблиц: из
  описания собирает структуру и отдаёт готовый .csv (открывается в Excel).

## Сборка установщиков

### Через GitHub Actions (рекомендуется)

Intel-Mac сборку не нужно делать локально — её соберёт macOS-раннер в облаке.
Workflow `.github/workflows/release.yml` собирает **Windows и macOS Intel**
одним пушем тега и вешает установщики в релиз.

1. Создай репозиторий на GitHub и запушь проект:
   ```bash
   git init && git add . && git commit -m "OmniSpace"
   git branch -M main
   git remote add origin https://github.com/USERNAME/omnispace.git
   git push -u origin main
   ```
2. Выпусти версию тегом — это и запускает сборку:
   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```
3. Во вкладке **Actions** пойдёт сборка (~10–15 мин). По завершении во вкладке
   **Releases** появятся `.msi`/`.exe` (Windows) и `.dmg` (macOS Intel).

Для публичного репозитория минуты Actions бесплатны. Можно также запустить
сборку вручную: Actions → «Сборка и релиз» → Run workflow.

На каждый push и pull request в `main` отдельный workflow `ci.yml` быстро
проверяет типы фронтенда и компиляцию Rust — поломки видны сразу, до выпуска тега.

### Локально

```bash
npm install
npm run tauri dev     # запуск в разработке
npm run tauri build   # установщик под текущую ОС
```

**Ход 11 (финал) — Дашборд + бэкап.**
- Rust: полный экспорт всех данных в JSON (13 таблиц, включая журнал). Проверено
  компиляцией; сквозной smoke-тест всего бэкенда (11 модулей) проходит.
- Фронтенд: главный дашборд («утренний бриф») — KPI (активные задачи, баланс,
  подписки, требующие внимания) и виджеты (задачи в работе, ближайшие события,
  расходы по категориям), всё из реальных данных, клики ведут в модули.
- Резервная копия в один клик: экспорт всей базы в JSON-файл.
